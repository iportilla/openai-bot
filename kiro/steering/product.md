# Product Overview

## OpenAI Bot Exercises

A hands-on learning repository for building chatbots and AI agents using the OpenAI API. The project progresses from basic chat completions to advanced implementations with memory, domain specialization, and voice interaction.

## Core Purpose

Educational labs demonstrating:
- OpenAI API integration patterns
- Conversational AI fundamentals
- Memory and context management
- Task-specific chatbot design
- Voice-enabled interfaces

## Key Applications

- **Lab 1**: Basic chat completion loops
- **Lab 2**: Conversation memory and state management
- **Lab 3**: Domain-specific bots (flower recommendations) and voice interaction
- **Lab 4**: Pizza ordering chatbot exercise
- **Voice Apps**: Streamlit-based voice chatbots with speech-to-text and text-to-speech

## Target Users

Students and developers learning to build conversational AI applications.
